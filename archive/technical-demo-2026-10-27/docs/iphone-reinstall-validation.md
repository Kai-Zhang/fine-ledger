# iPhone 删除 PWA 后重新安装验证

日期：2026-10-27。仅使用 8444 独立合成账本；不删除 8443 图标、不修改其数据库、不按域名清除 Safari 网站数据。

## 验收边界

系统删除动作由用户执行并记录实际菜单文字；程序不调用 `deleteDatabase` 代替系统删除。删除前先冻结完整业务基准，删除后从新主屏幕实例核验同一账本、全部嵌套业务字段、队列与冲突。保留初始化前账本是否存在、设备 ID、IndexedDB 标记和 localStorage 标记，以区分数据保留和重新初始化。

即使图标消失或设备 ID 改变，也不单独推定原本机存储已被清理。Safari 与主屏幕可能有不同存储上下文；若先在 Safari 重新初始化，再从新图标打开，报告会记录两个上下文的观察，并保留这一归因限制。

## 删除前

1. 服务端核对当前合成账本与恢复日志一致，保存一份应用快照和完整外部基准。
2. 用户从现有「厘序 P0」主屏幕图标联网打开新版，连接实验室。
3. 点「记录删除前基准」：同步后要求队列和冲突均为零，本机完整状态与服务端相同；记录来源、bookId、设备 ID、标记、游标、完整状态及 SHA-256，保存到服务端。
4. Codex 另存这份基准并核对 8443 业务指纹，然后再通知用户执行系统删除。

准备基准后不再运行自动故障测试、清空按钮或新建样例，避免验证期间改变基准。辅助标记写入只发生于 8444 实验室自身的存储。

## 系统删除与重新安装

1. 在主屏幕长按 **厘序 P0**，选择系统提供的删除操作并确认。记录实际选项，例如「删除 App」「删除书签」；不要仅移动图标或隐藏主屏幕页。
2. 在 Safari 打开同一来源 `https://zhangkaidemac-mini.local:8444/reliability.html`。如需重新输入口令，使用 `.local/reliability-iphone/connection.txt`；不要在聊天或报告中粘贴口令。
3. 连接实验室，再按 Safari 分享 → 添加到主屏幕，保持「作为网页 App 打开」（若系统显示此项），名称仍为「厘序 P0」。[Apple 网页 App 安装说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)。
4. 从新图标打开，连接后点 **重装后核验**。不要重新准备基准。
5. 用户反馈实际删除选项、是否要求重新输口令、核验提示原文；Codex 从服务端取回原始观测并与不可变基准和恢复日志交叉比较。

## 判定

- `fresh-local-recovery`：新主屏幕启动初始化前没有账本，初始化后完整匹配基准，证明该实例完成了联网恢复。
- `retained-local-data`：新主屏幕实例初始化前仍有删除前相同的设备 ID 与 IDB 标记；重装可用，但本次不证明删除清空了数据。
- `recovery-through-new-context`：另一个重装后的上下文曾无账本并恢复，最终主屏幕完整匹配；不据此断言原容器物理删除。
- `undetermined`：业务状态匹配，但删除对原容器的影响证据不足。

同一页面未重新启动、非主屏幕、来源改变、账本身份不同、任一字段哈希不同、待上传或冲突未清空，均不能判为重装核验通过。上述判定不替代用户对实际系统删除动作的确认。

# 厘序第一版前端视觉与交互基线

日期：2026-10-30（0.8.0 统一视觉）
依据：产品设计 0.8、MoneyWiz 3 实机调研、交互线框 v2。
参考技能：Anthropic 官方 frontend-design；Sites 的本地工程交付流程。技能仅指导设计，不改变产品范围或固定访问入口。

## 视觉决定

- 色彩：纸白 `#F7F8F5`、正文石墨 `#202A27`、松绿 `#205B4D`、浅绿 `#E7EFE9`、分隔线 `#DDE5DE`、支出陶红 `#AA4B3E`，次要文字 `#5D6B63`。业务正负号与文字同时表达含义；类别颜色仅用于类别图标与图形。
- 字体：中文使用设备原生 PingFang SC / system sans，数字启用等宽数字。避免在线字体依赖，离线与主屏幕安装保持一致。标题 24/32，正文 16/24，列表名称与金额 16/22，次要信息至少 12/16，总净值 32/40、录入金额 36/44；列表保持双行，金额对齐。
- 图标：本地打包 Lucide 线性图标，类目单独分配图标。账户图标、类目图标与操作图标保持相同笔画语言；品牌使用无文字的“账簿＋硬币”标识：深松绿底、纸白账页、暖金硬币；与类目及操作图标分开，强调小尺寸辨识度。
- 布局：手机四个固定主入口；主页紧凑分组列表与一行总净值。桌面固定侧栏、阅读宽度受控，账户与报表利用多列而不把手机页无限拉宽。
- 动效：只回应动作，展开/收起、表单导航及拖动落位；减少动态模式取消非必要动画。金额/报表不靠载入动画隐藏内容。

## 设计自检

这不是宣传页，不使用大幅 hero、巨型摘要、渐变或装饰卡片。早期拟用暖奶油底色，复核后改为偏中性的纸白；不使用衬线大标题，避免将财务工具做成生活方式落地页。视觉重点留给稳定的金额对齐、分组和图表的可核对性。

普通模式的新增和管理分开，管理中账户真实跟随拖动；类目拆分总额守恒；报表父子角度与金额守恒；入账状态点击图标切换；描述候选停靠键盘上方。不因为正式视觉换掉已确认交互。

## 工程与验收

React + TypeScript，Vite 打包，Dexie 本地事务，Lucide 图标，dnd-kit 实现跟手排序。业务计算用最小单位整数和精确比率，界面不自造余额。新建账本为空；示例账本与正式数据隔离。旧 P0 数据保留并进行版本化兼容，不要求用户清缓存或换端口。

在本轮完成本地可用的四类页面、账户/分类维护、编辑/删除/退款、拆分、入账、多币种转账、基础报表与导出。同步服务仍按 P2 单独交付；前端不能显示虚假的已连接状态。旧 MoneyWiz 原始备份、旧服务和证书不改。


## 品牌图标修订（2026-10-30）

在账簿＋硬币、展开双页账本、钱包＋收支箭头三个方向中，先采用账簿＋硬币。账簿两列短线表达逐笔记录，硬币区分普通笔记应用；不使用文字、首字母或固定币种符号。当前为首版待用户视觉 review，并非最终品牌定稿。

源文件为 `public/icon.svg`，使用 SVG 原生几何图形，192/512 PNG 与 iPhone 180px 图标从同一源文件输出。背景完全不透明、画布不预裁圆角，主体放在中央安全范围；应用内部按容器裁圆角。相同图形用于启动、侧栏、设置与建账页。

尺寸和简化原则参考 [Apple App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons)，PWA 的静态 PNG 接入参考 [Apple Web Clip 图标配置](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)。原应用身份、访问地址和端口不变。


## 统一视觉方案评审（2026-10-30）

三套可比较方向及颜色、字体、密度、图标、组件、深色模式规范见[视觉设计方案比较](visual-system-proposals.md)，建议纸白松绿。用户已选定纸白松绿，0.8.0 已统一实施，备份导入按原阶段推进。


## 纸白松绿实施规范（0.8.0）

`src/ui/pine-theme.css` 是全局视觉变量和组件节奏的入口；`src/style.css` 保留页面结构、手势、拖拽和可视视口处理。字体全部本地，图标使用 Lucide 1.75 线宽。账簿＋硬币品牌图标沿用同一 SVG 与既有安装 PNG，松绿底、纸白账页、暖金硬币在浅深色均保持识别，不改安装身份。

浅色参数见上文；深色背景 `#151B18`、表面 `#1F2822`、正文 `#E7EFE9`、次要文字 `#A4B3A9`、操作绿 `#A2D2B5`、按钮文字 `#132B20`、正向 `#91CCAE`、负向 `#F0A08F`、提示 `#DDB877`。主动作、正向金额和按钮前景各用独立语义变量。转账维持中性金额，方向由符号和交易类型表达。

手机页边 16；分组与面板使用 12 圆角，输入 10，主按钮 12。主按钮至少 48 高，页头图标操作 44 触区；归档继续用小图形与轻量触区，浮动主动作继续 52。既有安全区、底部导航占位、键盘联想条高度与导航动画几何保持原逻辑。

账户行 60，流水行 50；390×844 的同一组十笔流水在调整前后均完整显示十笔。日期分隔与组头压紧，以此容纳更清晰的 16/12 字号，不增加卡片层级。极窄屏拆分行只收起冗余箭头，保留类目、金额、锁定及移除控件。

新建账本的类目预设和编辑器预设采用松绿、陶棕、蓝灰、紫灰等协调色。已有账本颜色原样存储，编辑器继续显示原色；深色下仅对图形和图标提高亮度。图例、名称、百分比和金额同时表达分类，不单靠颜色区分。

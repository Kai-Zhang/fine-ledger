# 记账按钮位置与边缘返回

日期：2026-11-11。用户验收通过后已部署 NAS；未推送 Git。NAS 镜像为 `fine-ledger:0.14.5-nas-entry-gesture-760054d`，发布指纹为 `0.14.5-760054d8f5570596`；仅更新前端，保留当前 NAS 服务端。见[部署证据](evidence/2026-11-11-nas-entry-gesture/README.md)。

账户明细原先随着底部导航消失，记账按钮向下移动约 63px，降低单手触达性。现在沿用首页原来的右侧位置、52px 图标按钮及配色，在账户明细、全部交易和手势预览中保持屏幕高度稳定。去掉居中视觉原型的查询参数开关和无操作按钮，恢复真实记账入口及当前账户默认值。按钮周围仅有 8px 透明保护区域，列表保持原高度并为末笔提供滚动余量。

左侧返回起点由 24px 扩至 44px；触摸捕获、导航方向与行侧滑共同使用同一份边缘定义，右侧前进保持 24px。方向观察允许短距离斜向起步，明显纵向滚动或反向运动不导航，持续模糊斜向也让给内容。完成返回仍使用原距离和速度条件。新增边缘区域不在 touchstart 阶段阻止默认行为；原 iOS 历史保护区域维持 24px。返回拖动后的残余点击被抑制，后续新触摸和键盘激活不受影响。带有自身手势的图表、候选条、输入控件与拖动手柄避开页面手势。

- `npm run check`、`npm run build` 通过。构建仍提示 Lucide 的 `use client` 指令和大块资源警告。
- 全量 182 项测试通过。沙盒内初次运行有两项因无法监听本机端口而失败；允许监听临时端口后重跑全部通过。
- Chrome 独立临时配置、示例账本中，通过 DevTools 触摸输入检查左侧 12/24/36/44px 返回、右侧前进、斜向起步、短滑回弹、45px 外起滑不返回，以及新增区域内正常纵向滚动。

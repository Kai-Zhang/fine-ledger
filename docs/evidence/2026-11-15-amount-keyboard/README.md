# 金额计算键盘 · 2026-11-15

## 数字输入盘点

| 入口 | 字段 | 本次处理 |
| --- | --- | --- |
| 记账 / 编辑交易 | 总金额（支出、收入、退款、转出、余额调整） | 共用计算键盘；余额调整允许负数 |
| 拆分类目 | 每项金额 | 共用计算键盘；离开已修改项后自动锁定；提供“锁定并下一项” |
| 跨币种转账 | 转入金额 | 共用计算键盘，按转入币种精度 |
| 转账附加项 | 独立手续费 | 共用计算键盘 |
| 历史外币交易 | 原始消费金额 | 共用计算键盘，按原始币种精度 |
| 新建账本 | 第一个账户的当前余额 | 共用计算键盘，允许负数 |
| 账户编辑 | 期初余额、信用额度 | 共用计算键盘；期初余额允许负数 |
| 入账确认 | 实际入账金额、每项类目金额 | 共用计算键盘，按账户币种精度 |
| 交易筛选 | 最低金额、最高金额 | 共用计算键盘；保留先选择金额币种的原有校验 |

共 12 处金额输入组件（总金额按交易类型复用、类目按行复用）。已无金额字段使用系统数字键盘。

下列数字控件保留原有交互：

- 备份策略的 5 项整数：间隔分钟、近期小时、每日天数、每周周数、手动保留数。它们受独立的 min/max 约束，保留原生数字输入及表单校验。
- 交易、转入交易的日期与时分秒、账户期初日期、筛选和报表的起止日期：保留日期选择器与有界的时间输入。
- 净值与趋势图表的范围滑块：属于图表浏览控制，保留滑动。
- 名称、备注、搜索、密码、服务地址即使含数字仍属于文本，不改为计算键盘。

## 行为

- 点击金额打开底部自定义键盘，输入框 `readOnly` / `inputMode="none"`，不请求系统软键盘；文字字段继续使用系统键盘。
- 支持加减乘除、小数点、退格、清空、等号、物理键盘和粘贴算式。先乘除后加减。
- 使用 BigInt 分数运算，按币种最小单位对最终结果四舍五入，避免浮点精度误差。JPY 无小数，支持其他币种精度。
- 合法结果实时写回表单；未完成或非法算式在键盘内提示，不能悄悄保存上一结果。可用“取消计算”恢复进入该字段时的金额及受影响的拆分分配。
- 余额支持负数与正负号按钮；一般金额拒绝负数；除以零、过长和非法算式均有错误反馈。
- 离开已修改的拆分金额时，先校验分配，再锁定；未修改的项不会因为浏览而自动锁定。显式锁按钮仍可解锁。剩余金额只分配到未锁定项。
- 键盘进入 popover 顶层，原生 dialog 内也可操作；键盘展开后缩小可滚动表单区域，聚焦项滚动到可见区域。
- 弹窗仅在按下和抬起均属于背景点击时关闭，避免键盘引起弹窗移位时误关闭。

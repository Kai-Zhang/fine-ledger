# 0.10.0 同源连接与远端账本恢复

日期：2026-10-31。最终发布：`0.10.0-8eb6cea4a735dc0f`。

首次打开改为同级的“新建账本”和“连接已有账本”，选择新建后再填写账户表单；两个入口间距 16px。连接固定使用当前网页来源，只填写访问口令及设备名称。验证后预览远端名称、币种和数量，点击“下载并开始记账”将完整账本写入本机，随即进入已有账户、交易和报表功能。

已有本机账本从“设置 → 远端账本与设备 → 从远端恢复到本机”操作。预览显示替换影响和本机操作数量，勾选确认后替换。替换前保留一份本机账本、操作、草稿和修订，可随完整备份导出。下载不改写服务器，不重放旧操作，不合并本机修改。

快照先验证协议、账本身份、恢复代次、业务关系、实体版本和 SHA-256。IndexedDB 单事务保存工作副本及远端基线/水位、清理旧活动 outbox/草稿/修订并保留前副本；本机外观保留。预览后本机内容或草稿变化会拒绝替换，避免覆盖另一页面刚保存的内容。此能力不是完整的旧 outbox 升级、增量同步、冲突解决或服务恢复后的自动核对。

## 验证

- `npm run check`、`npm run build` 通过；`npm test` 共 74 项通过，新增 9 项客户端恢复测试。
- 认证后的实际服务快照通过客户端恢复函数保存为可用的本机账本，余额精确，恢复后 outbox 为空；随后本机修改不影响服务及基线。
- 覆盖错误摘要、非法关系、缺失/重复实体版本、错误账本/代次、本机并发修改与草稿变化、两次并发恢复，以及保存中途失败后的完整事务回滚。
- 隔离浏览器从空库连接、预览并下载 5 个账户/28 笔记录，账户余额与夹具一致，刷新保留，原交易和支出分类报表可用。制造一条本机修改后，界面显示其不会合并；替换按钮默认禁用，勾选后恢复并回到账户页。
- 390px 与 320px 入口无横向溢出，390px 实测两入口间距 16px；独立的新建账本流程通过。
- 停止隔离测试服务后重新加载，已下载的本机账本从缓存启动，账户和余额仍可读取。见下图。此检查不替代 iPhone 飞行模式冷启动。
- 浏览器链路证据来自 `0.10.0-5da9aa4e569c60ed`；随后仅将未注册的下载图标改为现有云图标，形成最终发布。最终 8445 的 12 项页面/资源响应经原 CA 校验，均为 200 且逐字节匹配构建，见 [HTTPS 资源核对](evidence/2026-10-31-restore/https-resources.json)。原 8445 进程和模拟账本保持运行，未重启或重置。

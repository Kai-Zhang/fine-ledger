## 口令与退出语义

口令控制远端访问权限：知道 URL 或连接同一局域网，不等于能下载、上传或管理账本。服务端使用带盐 scrypt 校验值，会话使用 Secure/HttpOnly/SameSite Cookie，变更接口还有同源与 CSRF 校验。设备撤销终止已有会话；口令泄露时需由管理者重置口令并撤销会话。口令不加密本机 IndexedDB，不能阻止已经能使用该设备的人查看已下载内容。

当前单账本产品不加入含义模糊的“退出账本”。保留“断开远端连接”：撤销当前设备会话、清除 Cookie，本机副本仍可离线使用。若未来引入账本管理，返回开始页应保留副本并提供继续使用，移除副本或锁定需另行定义。

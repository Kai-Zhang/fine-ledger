更正（2026-11-01）：本轮记录器只在摘要存在时采集坐标，未统计新挂载期间摘要缺失，因而漏掉手势预览切换到正式页面时的一帧跳动。不能由本记录宣称返回闪烁已经消除；录屏定位、修复前后对照见 [0.12.6 记录](frontend-review-v0.12.6.md)。

## 调整

- “最近同步”不再使用随地区格式变化的 `toLocaleString()`，采用设备时区的 `YYYY-MM-DD HH:mm:ss`、等宽数字和不换行时间。
- 待上传数量从时间尾部分离，固定为摘要第二行；零条仍保留这一行，避免上传完成时后续内容移动。错误和需要核对的状态仍正常显示。
- 子页返回或手动刷新已有连接时，保留已知连接状态，后台检查不再将“已连接”短暂改成“正在校验”；检查失败仍显示不可达状态。
- 版本来源统一为 `package.json.version`。Compose 通过 `npm run container -- …` 读取版本；HTTP/TLS 烟测共用镜像引用解析，移除三处 `0.12.0` 默认值。支持显式镜像标签或 digest，直接使用 Compose 却未指定镜像时明确失败。更新部署说明，历史验收记录保持原版本。

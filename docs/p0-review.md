# P0 第一版交互评审

日期：2026-10-27。产品：厘序；codename：`fine-ledger`。本轮交付可运行的 PWA 产品原型，等待用户 review，P0 整阶段尚未验收。

## 打开与范围

在仓库根目录执行 `npm start`，打开 <http://127.0.0.1:4180/>。不需要安装第三方依赖。使用合成账户和交易；首次打开需要联网获取应用壳。已沿用原证书准备 [iPhone HTTPS review 入口](p0-iphone-review.md)，本机 localhost 验证不等于真机完成。

默认 6 个账户、15 笔虚构交易。本轮浏览器验证新增了 4 笔合成记录，所以当前预览来源有 19 笔；新浏览器来源仍从初始样例开始。没有读取 MoneyWiz 真实账本。当前浏览器数据可从设置导出，不提供导入恢复入口。

## 设计方向

以账户作为稳定上下文：账户首页 → 账户交易记录 → 新增，另提供账户卡片的快捷“+”。录入不用每次从长账户列表重新选择。桌面常用账户固定在侧栏；手机使用底部导航和底部表单。暖白底色、墨绿主操作、原币余额与紧凑交易行用于突出主要信息。

应用内描述候选跨账户复用同一收支类型的历史：空输入最多 8 项，输入后包含匹配，前缀优先。点候选或键盘选候选时带入上次类目；类目按一级展开二级。手动选择的类目不会因随后编辑描述而被清空。选择另一个历史描述会按该描述重新带入类目。

旅游项目与备注默认折叠；恢复有内容的草稿时主动展开。退款归属于原支出详情；余额调整归属于账户菜单。日常页面不出现数据库、同步协议和服务连接状态，开发者信息开关默认关闭。保存失败仍直接显示错误并保留输入。

MoneyWiz 2 的账户路径以本次用户描述为准；没有把后续版本截图当作 MoneyWiz 2 的界面证据。可访问的官方后续版本说明与同类应用用作交互参考：

- [MoneyWiz 官方桌面指南](https://assets.wiz.money/MoneyWiz3_Desktop_Guide.pdf)：在原交易上触发退款，支持部分退款。
- [YNAB 官方账户与交易记录说明](https://support.ynab.com/en_us/getting-started-ynab-basics-and-key-terms-BJCaIHaTZe)：账户内的交易记录用于对应实际银行流水。
- [YNAB 描述/收付款方分类规则](https://www.ynab.com/whats-new/categorization-that-matches-your-habits)：历史输入可辅助分类。本版按用户指定的“该描述上次类目”实现，不采用其其他推断规则。

## 推荐评审路线

| 操作 | 预期体验 |
| --- | --- |
| 首页点招商银行 | 进入该账户交易记录，右上角可记一笔 |
| 输入金额，点最近描述 | 直接填描述与上次二级类目 |
| 描述输入“咖啡” | 包含该词的描述都可选；前缀命中排在其他子串命中之前 |
| 点类目 | 先看到一级分组，展开后选二级项 |
| 保存，再记一笔 | 当前账户保留，新金额和描述清空，项目与备注不偷偷沿用 |
| 关掉未完成表单，再次打开同一账户 | 恢复该账户草稿 |
| 打开消费时间 | 可选到分钟；导出为含秒 UTC ISO 时间，秒为 00 |
| 点某笔原支出 → 记录退款 | 默认剩余可退额，可部分退款，继承类目和项目，超额拒绝 |
| 账户右上角更多 → 调整余额 | 输入实际余额与原因，保存独立差额，不计收入和支出 |
| 设置 → 开发者信息 | 默认关闭，主动开启才显示本地库和离线缓存状态 |

本轮希望先讨论：账户首页的卡片密度、记一笔的字段顺序、候选数量及表单高度。设计可以继续调整，不把第一版原型当作已经定稿。

## 已执行验证

- `npm run check`：全部脚本语法通过。
- `npm test`：10/10 通过，覆盖精确金额、非法精度、最近描述去重、子串/前缀排序、最近类目、收支类型隔离、退款上限与继承、转账守恒和日期格式。
- 内置真实桌面浏览器：走通账户进入、连续保存、历史描述带类目、二级展开、手动类目保留、草稿重开、部分退款、超额退款拦截、账户余额调整、开发者默认隐藏。
- 手机尺寸模拟：390 × 844，检查账户页、录入候选、滚动表单及固定保存区。是桌面浏览器尺寸模拟，**不是真实 iPhone 软键盘与主屏幕验收**。
- 实际停止本轮 4180 服务（确认该端口无监听），关闭页面并在新标签页打开相同来源：应用壳及账本可用，草稿恢复；保存 12.34 CNY 后重载页面，记录、零食水果类目、秋日杭州项目和备注保留。
- 停机时通过设置导出 JSON，随后从下载文件检查：19 笔交易、4 笔新增、4 条操作意图、0 草稿；新增 ID 唯一、时间含秒且秒为 00；退款关联及可选字段完整。导出是原型状态快照，操作意图不是已完成 NAS 同步的回执。

## 未完成与后续门槛

- 新版尚未完成目标 iPhone HTTPS 安装、真实软键盘、强退/系统回收和保存性能验收；旧 demo 的证据保存在归档目录，不直接套用。
- NAS 认证、同步、冲突、恢复、真实迁移未接入。跨币种转账、退款到其他账户、拆分退款、还款成本与对账留待 P2–P5。
- P0 使用直接 ES modules 和整体 IndexedDB 账本，仅用于本轮交互规模。正式 React/TypeScript 工程化、领域实体拆分、描述索引及大账本性能应在 P1 按技术设计落实。
- 本版无交易编辑/删除、账户/类目维护、导入恢复和历史月份报表入口；原型不替换 MoneyWiz。
- 当前离线更新采用完整预缓存、等待全部旧页面关闭后接管，不在录入中强制刷新。更完善的可见更新提示在 P1 增加。

旧 `data/`、`.local/` 原地保留且被 Git 排除。归档后的旧服务不作为本轮 review 入口，也不保证旧 URL 仍提供原页面；本轮入口统一使用 4180。

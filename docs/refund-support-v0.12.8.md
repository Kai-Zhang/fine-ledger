# 正式退款支持与首次导入（0.12.8）

退款关联表示来源，不再施加同币种或累计金额上限。超额与跨币种均可从原支出新增、编辑、删除/恢复和双端同步；原交易金额不变。到账账户可选择其他币种，改变币种时清空录入金额，要求输入实际到账金额，不推断汇率。原金额始终显示原账户币种；已有退款分别按币种汇总。同币种正差额仅用于预填，有跨币种关联或差额非正时不预填。v2 的历史关联继续可读，编辑时转为普通关联。

成本冲减、还款覆盖及汇兑差额仍需独立证据和容量约束，本次不从跨币种关联虚构成本。对账批次和预算仍仅保留迁移档案，未补齐操作界面；本机完整备份保留档案，当前远端账本快照不托管 legacy 源档案。

## 首次接入

1. 部署空数据目录的服务，配置 HTTPS 及服务访问口令。
2. iPhone Safari 访问服务地址，添加到主屏幕，再从主屏幕打开。
3. 选「从备份文件恢复」，导入 v3 完整 ZIP 并确认预览。无需先建空账本；恢复会替换当前本机整本，不是追加交易。
4. 核对本机内容后，进入「设置 → 远端账本与设备」连接同一服务。
5. 选择「使用本机账本建立远端 → 建立远端并启用同步」，等待已同步、待上传为 0。
6. 后续设备从同一地址选择「连接已有账本」下载。

每个服务实例托管一个账本；当前 8445 演示库也是普通账本，未被本次迁移替换。已有远端不能自动与不同身份的本机账本合并。应使用全新数据目录做个人正式实例。手机 Safari 与主屏幕的本机数据独立，导入应在计划日常使用的主屏幕 App 内完成。

修复首次发布流程：仅在服务确认初始化快照后清除文件恢复的待核对标记，避免下一轮同步错误要求重新连接；未改变连接已有远端时的核对保护。

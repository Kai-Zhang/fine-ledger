# 分类环图精细选择（0.12.12，2026-11-02）

上一版选中弧线的圆头会伸入相邻细扇区；仅对实际 SVG 描边点击，也使小于 1px 的扇区难以命中。本版把图形显示和命中模型分开。

## 结果

- 完整类目集合生成稳定的多色图表映射，大类区分色相、子类保持家族关系，深色提亮；即使同组 40 子类也有不同展示颜色。不修改已有类目颜色或金额。
- 所有弧线保持平头，选中项增加浅色外沿、其他项变淡；高亮及小项指示线 pointer-events 为 none。圆心显示名称、金额、百分比；0.08% / 0.02% / 0.04% 不再舍成 0.0%。
- 点按使用角度及环层级命中，包含描边间隙，绕过细弧的物理宽度限制。长按 300ms 后按横向距离逐项切换，锁定内外环，不按小扇区的狭窄角度跳选。选择带浮在触点另一半区，松手保持选择并收起临时带。
- 精细选择按钮支持手动打开相邻项，并可直接点按或拖动；列表正文同样能选中图表，List 图标单独打开明细。下钻返回保留类别和环层级。键盘方向键移动到相邻项并转移焦点。
- 进入精细选择前，纵向手势取消选中、放行页面滚动；多指操作取消单指选择。只监听图表 SVG 的触摸，完成按钮等辅助图标不被截获。

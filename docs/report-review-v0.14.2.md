# 0.14.2 报表目录与余额视图调整

2026-11-03。已发布到原 8445 HTTPS 入口，版本指纹 `0.14.2-9b03c3de48e00ce6`。

- 目录按业务语义分组：账户（余额与净值、收支结余）、支出（分类、趋势）、收入（分类、趋势）、项目（项目支出）。原常用报表名称、筛选和排序保留。
- 原币余额的账户选择只列币种与账本主币不同的账户。主币账户仍可从账户详情、净值构成或已有常用报表查看余额历史。
- 切换控件使用 14/20 字体及 28px 视觉标签，保留 44px 触区。
- MoneyWiz 将所选账户的资金流入流出称为现金流并归在账户组。[MoneyWiz 官方手册](https://assets.wiz.money/MoneyWiz_Guide.pdf)。厘序这张报表统计收入减净支出，排除转账本金和余额调整，因此采用「收支结余」及天平图标，归在账户组。统计规则与保存格式不变。

日期：2026-10-31。

## 交付

通用自托管 Fastify / SQLite 服务，不绑定设备品牌、IP、域名或家庭网络。提供独立启动命令、Docker 镜像和 Compose 配置，网页与 API 同源。访问密码由部署文件初始化，设备会话支持撤销和管理端重置；服务名称与备份策略可在网页设置修改，来源、端口与卷由部署配置管理。

业务表保存显式关系与外键。上传使用服务端版本、操作摘要与持久回执，每条业务命令原子校验和提交；拉取按完整提交批次分页。完整快照含水位和校验值；初始化只允许空服务，当前 JSON 导出文件不重放旧 outbox。已加入浏览器登录、设备列表、备份与运行设置，以及合成导入预览/确认路径。

备份先用本地磁盘，自动任务默认关闭；支持手动一致性快照和配置保留策略。恢复为停服管理命令，先保全当前状态，再恢复目标并更换代次、撤销会话。文件锁阻止同目录多个实例或在线恢复。

## 边界

本轮未部署至 NAS，未修改 NAS/路由器配置或重启其服务。Docker 与桌面浏览器证据不替代真实 NAS 的持久卷、断电及目标 iPhone 的 Safari→主屏幕安装、Cookie/离线生命周期验证。

客户端自动上传/增量应用、基线/outbox 升级、多标签协调、冲突解决、恢复核对、本机回导、通用 ZIP 交换格式仍待后续 P2 交付。服务登录/初始化成功不等于本机账目已同步，P2 整阶段未验收。MoneyWiz 全量转换、正式迁移及互联网接入继续按既定后续范围处理。

部署和协议说明见 [server-deployment.md](server-deployment.md)。

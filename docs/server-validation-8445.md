## 推荐观察流程

初始流程的新建/连接页均为左上角返回图标；沿用左边缘右划返回、右边缘左划前进。服务概览的设备、备份、策略及名称编辑分为子页，不再在一屏堆放表单。断开远端连接会清除当前会话并撤销设备授权，本机副本仍保留。

首次访问无本机账本：选择与“新建账本”并列的“连接已有账本”，填写访问口令、设备名，验证后预览远端账本，点击“下载并开始记账”。无需填写地址，服务来源固定为当前网页。

已有本机账本：打开“设置 → 远端账本与设备”，登录后点击“从远端恢复”。核对远端名称和数量，确认替换影响，再点击“确认恢复并打开”。旧副本及其操作、草稿、修订保留一份，可随完整备份导出；旧操作不会重放或上传。无需清空站点数据或删除主屏幕图标。

## 自动化验证

`npm test`：80 项全部通过，其中服务端 22 项、客户端恢复 9 项。恢复测试覆盖真实认证快照到本机的链路、精确余额、基线保存、校验失败、替换前保全、写入失败回滚、预览后本机变化和并发恢复。此前新增的服务端测试涵盖：

- 过期会话、伪造 CSRF、非法关系/金额/日期、过大或缺少版本前提的请求。
- 数据库写入中途故障完整回滚，原操作 ID 可安全重试；依赖未完成的命令随后重试成功。
- 两设备并发、每条命令重复提交，最终余额精确、记录无重复、游标无缺口。
- 子进程提交后被 SIGKILL，重开后仍保留账本、回执和数据库完整性。
- 备份保留数量、分层历史清理；即使重新计算校验值，也拒绝有外键损坏的备份并保留当前账本。
- 交易墓碑删除的幂等性、错误账本/恢复代次保护、TLS 启动失败后释放实例锁。
- 完整快照不携带本机主题偏好，并保留报表与精确时间戳。

以上故障测试全部使用临时隔离目录，不终止 8445 评审服务。SIGKILL 测试证明进程异常退出后的持久性，不能替代真实硬件断电测试。

真实 8445 HTTPS 请求还验证了原 CA 信任、Secure/HttpOnly 会话、快照校验值、静态资源及设备撤销，证据见 [https-8445-smoke.json](evidence/2026-10-31-server/https-8445-smoke.json)。内置测试浏览器未信任此本地 CA，未绕过证书检查；本轮尚无新增 iPhone 交互验收证据。此前 Docker 验证见 [原交付记录](server-review-v0.9.0.md)，不是本轮新增变更的镜像验收。

## 本机管理命令

```sh
npm run service:review:status
npm run service:review:stop
npm run service:review:start
```

启动命令构建网页并使用保留的模拟数据。停止命令只停止本脚本创建的匹配进程，数据保留。个人账本导出可继续从本机设置完成；本次模拟服务已经初始化，不接受再次覆盖初始化。客户端下载恢复是另一个方向，不会覆盖服务端账本。

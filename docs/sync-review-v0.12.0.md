日期：2026-10-31。最终发布 `0.12.0-c7b7c6b1b5bdf475`。当前入口维持 `https://zhangkaidemac-mini.local:8445`，复用原 P0 证书、端口和隔离合成账本。NAS/路由器未修改，主屏幕图标未删除，也未清理站点数据。本轮只操作厘序、iPhone Safari、Mac Safari 检查器及系统 iPhone 镜像与文件选择/保存面板；应用切换器中只关闭厘序卡片。

## 能力补齐

- 基线与工作副本分离；保存与操作日志同事务提交。请求先冻结，再发送，重试复用操作身份和内容。
- 上传回执不提前推进拉取水位；完整批次应用与基线/版本/水位同事务提交。普通独立修改合并，同一实体及关联冲突暂停。
- 多标签租约与过期接管保护；前台/联网重试、认证过期保留本机内容；编辑时暂停远端应用，旧编辑器不能覆盖并发保存。
- 生产文案的冲突核对和恢复代次核对；拒绝操作不反复自动上传。核对期间远端再次变更会更新对比并重新确认。
- ZIP 完整备份、摘要及关系校验、兼容 JSON v3、本机回导预览/原子替换/恢复前副本。文件恢复后的旧请求不会自动上传，重新接入先核对。
- 空服务可从本机账本初始化，初始化请求丢失响应后也可幂等恢复。

## 现场发现并修正

- 服务暂时不可达时，已有基线的同步页误呈登录表单；改为本机同步状态与待上传数量，保留重新检查入口，已在最终版本真机复测。同步恢复成功后会重新检查概览连接状态。
- 认证失效时，已打开的服务页可能保留旧会话控件；现在自动转入重新授权状态，本机数据继续保留。
- 前台切换导致的中止异常不再直接展示英文 `Fetch is aborted`。
- 空闲队列不再重复清空，避免观察器误触发连续同步；增加真实 Dexie 观察器回归测试。
- 强制重试若碰上上一轮请求仍在运行，协调器会保留重试意图，避免重新登录后丢失本轮启动。
- 真机镜像回导发现普通鼠标指针被边缘手势容器无条件捕获，导致原生文件选择器无法激活；仅在实际开始边缘手势时捕获指针，更新后真机已能打开文件选择器。
- 冲突比较补全账户/类目顺序、图标、分组、报表筛选及精确日期，只展开不同字段，减少手机上的重复阅读。

最终版本真机复核已于 2026-10-31 解锁后完成。见 [最终 Inspector 记录](evidence/2026-10-31-sync/iphone-final-confirmed-inspector.txt)：发布 `0.12.0-c7b7c6b1b5bdf475` 与服务发布一致，standalone=true、Service Worker controller 存在、idle、cursor=5、29 笔、合成记录 345 分；待上传数为 0，无冻结请求、无未解决冲突。同步页显示“已连接／已同步”，[最终截图](evidence/2026-10-31-sync/iphone-final-synced.png)。实际边缘手势验证了从同步页左边缘右划返回设置，以及右边缘左划前进回到同步页：[返回](evidence/2026-10-31-sync/iphone-final-gesture-back.png)、[前进](evidence/2026-10-31-sync/iphone-final-gesture-forward.png)。原主屏幕图标保持，未清理本机数据。本项锁屏阻塞已经解除。文件回导 [预览](evidence/2026-10-31-sync/iphone-zip-preview.png)、[恢复后](evidence/2026-10-31-sync/iphone-zip-restored.png)、[同步暂停](evidence/2026-10-31-sync/iphone-file-unlinked.png)；离线界面修复已 [真机复测](evidence/2026-10-31-sync/iphone-offline-fixed.png)。
